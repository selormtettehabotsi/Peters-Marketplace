## Objective

Turn the marketplace into a full Progressive Web App (PWA) that is installable on phones, works offline, caches aggressively for slow networks, and loads fast on poor connections. This module focuses on the service worker configuration, web app manifest, offline fallback, and performance optimizations.

---

## Why PWA Matters for This Project

St. Peter's Hostel students are on:
- **Slow mobile data** (3G/2G) — MTN, Vodafone, AirtelTigo
- **Unstable hostel Wi-Fi** — shared among hundreds of students
- **Budget Android phones** — limited memory and processing power

A PWA solves this by:
- Caching the app shell so the UI loads instantly, even offline
- Caching images so they don't re-download every time
- Working offline with stale data (last seen products)
- Being installable (home screen icon, no browser chrome)

## Part 2: Service Worker Caching Strategy

The service worker is auto-generated by `vite-plugin-pwa` using Workbox. The caching strategies are defined in `vite.config.js` (Module 00). Here's a breakdown of what's cached and how:

### Caching Table

| What | Strategy | Cache Name | Max Entries | Max Age | Reason |
|------|----------|-----------|-------------|---------|--------|
| App shell (HTML, CSS, JS) | **Precache** | `workbox-precache` | All | — | Always available offline |
| Google Fonts | **Cache-First** | `google-fonts-cache` | 10 | 1 year | Fonts never change |
| Product images (Supabase Storage) | **Cache-First** | `product-images` | 60 | 30 days | Serve from cache, update in background |
| API responses (product listings) | **Network-First** | `api-cache` | 50 | 5 min | Try network, fall back to cached |
| Static assets (SVG, ICO, PNG) | **Precache** | `workbox-precache` | All | — | Part of the app shell |

### Strategy Explained

- **Precache**: Downloaded and cached during service worker install. Always served from cache. Updated when a new service worker is deployed.
- **Cache-First**: Check cache first → if found, return immediately. If not, fetch from network, cache it, return it. Best for assets that rarely change.
- **Network-First**: Try network first → if successful, cache and return. If network fails, return cached version. Best for API data that should be fresh but has a fallback.

### Offline Detection Banner

Add an online/offline status detector in `src/main.js`:

```javascript
// Detect online/offline status
function setupOfflineDetection() {
  const showBanner = () => {
    let banner = document.getElementById('offline-banner');
    if (!banner) {
      banner = document.createElement('div');
      banner.id = 'offline-banner';
      banner.className = 'offline-banner';
      banner.textContent = '📡 You\'re offline — showing cached data';
      document.body.appendChild(banner);
    }
    banner.classList.remove('hidden');
  };

  const hideBanner = () => {
    const banner = document.getElementById('offline-banner');
    if (banner) banner.classList.add('hidden');
  };

  window.addEventListener('online', hideBanner);
  window.addEventListener('offline', showBanner);

  // Check initial state
  if (!navigator.onLine) showBanner();
}
```

## Part 4: Image Performance Optimizations

### Lazy Loading

All `<img>` tags in product cards and galleries should have:
```html
<img loading="lazy" decoding="async" />
```

### Blur-Up Loading Effect

Product cards should show a blurred tiny thumbnail while the full image loads:

```javascript
/**
 * Create a lazy-loaded image with blur-up effect.
 * @param {string} thumbnailUrl - Tiny thumbnail (blurred, < 1KB)
 * @param {string} fullUrl - Full quality image
 * @param {string} alt - Alt text
 * @returns {HTMLElement}
 */
export function createLazyImage(thumbnailUrl, fullUrl, alt) {
  const wrapper = document.createElement('div');
  wrapper.className = 'lazy-image-wrapper';

  const img = document.createElement('img');
  img.src = thumbnailUrl || fullUrl; // Start with thumbnail
  img.alt = alt;
  img.className = 'card-image blur-up';
  img.loading = 'lazy';
  img.decoding = 'async';

  if (thumbnailUrl && thumbnailUrl !== fullUrl) {
    // Load full image in background
    const fullImg = new Image();
    fullImg.onload = () => {
      img.src = fullUrl;
      img.classList.add('loaded'); // Removes blur
    };
    fullImg.src = fullUrl;
  } else {
    img.onload = () => img.classList.add('loaded');
  }

  wrapper.appendChild(img);
  return wrapper;
}
```

### Image Format

All uploaded images are converted to **WebP** during upload (Module 06). WebP is:
- 25-35% smaller than JPEG
- Supported by all modern browsers
- Better quality at smaller file sizes

## Part 5: Additional Performance Optimizations

### 1. Code Splitting

Vite automatically code-splits by dynamic import. Each page module should be lazy-loaded:

```javascript
// In router setup — lazy load pages
addRoute('/', async (params, el) => {
  const { renderHomePage } = await import('./pages/home.js');
  renderHomePage(el);
});

addRoute('/products', async (params, el) => {
  const { renderProductsPage } = await import('./pages/products.js');
  renderProductsPage(el);
});

// ... etc — each page is a separate chunk
```

### 2. Preconnect to Supabase

Already done in `index.html`:
```html
<link rel="preconnect" href="https://YOUR_PROJECT.supabase.co" />
```

### 3. Font Loading Strategy

Already using `display=swap` in the Google Fonts URL to prevent font-blocking:
```html
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&family=Outfit:wght@600;700&display=swap" rel="stylesheet" />
```

### 4. Skeleton Loaders

Every page that fetches data should show skeleton placeholders immediately while data loads. This is already defined in Module 01 (`animations.css`) with the `.skeleton` class.

### 5. Debounce API Calls

Search input and filter changes should be debounced (300ms):

```javascript
export function debounce(fn, delay = 300) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}
```

## Part 6: PWA Install Prompt

Capture the browser's install prompt and show a custom install banner:

```javascript
let deferredPrompt;

window.addEventListener('beforeinstallprompt', (e) => {
  e.preventDefault();
  deferredPrompt = e;
  showInstallBanner();
});

function showInstallBanner() {
  const banner = document.createElement('div');
  banner.className = 'install-banner animate-slide-up';
  banner.innerHTML = `
    <div class="container flex items-center justify-between">
      <div class="flex items-center gap-3">
        <span class="text-lg">🏪</span>
        <div>
          <p class="font-semibold text-sm">Install SP Market</p>
          <p class="text-xs text-muted">Add to home screen for quick access</p>
        </div>
      </div>
      <div class="flex gap-2">
        <button class="btn btn-ghost btn-sm" id="install-dismiss">Later</button>
        <button class="btn btn-primary btn-sm" id="install-accept">Install</button>
      </div>
    </div>
  `;
  document.body.appendChild(banner);

  document.getElementById('install-accept').addEventListener('click', async () => {
    deferredPrompt.prompt();
    const { outcome } = await deferredPrompt.userChoice;
    deferredPrompt = null;
    banner.remove();
  });

  document.getElementById('install-dismiss').addEventListener('click', () => {
    banner.remove();
  });
}
```
